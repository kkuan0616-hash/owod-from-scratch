# W1 对照实验：epoch 数对"从零训练"的影响

- 日期：2026-10-31
- 目的：验证"训练 10 个 epoch 是否已经足够"
- 变量控制：**只改 epochs**，其余全部固定

## 实验设置

| 项 | 值 |
|---|---|
| 模型 | YOLO11n（`yolo11n.yaml`，**从零训练，无预训练权重**） |
| 数据 | gesture，975 训练 / 104 验证，5 类 |
| 输入尺寸 | 640 |
| batch | 16 |
| 优化器 | 自动（AdamW） |
| seed | 0 |
| 环境 | RTX 5060 Laptop 8GB / torch 2.11.0+cu128 |
| 脚本 | `scripts/train_w1.py` |

## 结果

| 组 | epochs | mAP@0.5 | mAP@0.5:0.95 | Precision | Recall | 训练耗时 |
|---|---|---|---|---|---|---|
| A | 10 | 0.0189 | 0.0059 | 0.0034 | 0.9917 | 144 s |
| B | 50 | **0.5924** | **0.3641** | 0.4321 | 0.8089 | 571 s |

## mAP@0.5 增长曲线（每 5 轮采样）

```
A（10 轮）: 0.004 0.005 0.014 0.012 0.012 0.016 0.016 0.017 0.019 0.017
B（50 轮）: 0.004 0.024 0.099 0.258 0.312 0.351 0.411 0.473 0.512 0.533 → 0.592
```

## 结论

1. **epoch 数是从零训练的决定性因素**：mAP@0.5 从 0.019 提升到 0.592，**31 倍**。
2. **验证集 box loss 从 2.380 降到 1.429**，说明模型在 A 组阶段连"框画在哪"都没开始学。
3. **A 组的 P=0.003 / R=0.99** 是典型"乱框"状态：到处画框所以召回极高，但几乎没框对。
4. **B 组第 50 轮仍是历史最佳，曲线仍在上升** → 50 轮还没收敛，继续训练仍有收益。
5. 由此推断：**10 个 epoch 从零训练 ≈ 什么都没学到**。以前那次 10 轮拿到 0.909，是因为用了预训练权重，不是从零。

## 局限（写论文时要写进去的部分）

- 只跑了 1 个 seed，指标可能有 ±0.03 的波动，结论需 3 seed 复核。
- 验证集只有 104 张，单轮指标抖动大。
- 未与"预训练权重 + 10 epoch"对比，因此无法量化预训练带来的收益 —— 这是下一步实验。
