## 5. 已经踩过并解决的坑（避免重复）

1. 在 **cmd** 里粘 PowerShell 脚本 → `'#' 不是内部或外部命令`、`'$root' 不是内部或外部命令`。Git 命令两个窗口一致，但变量/注释/建文件语法不同。
2. 远程地址写错用户名（`KKUAN` ≠ 实际 `kkuan0616-hash`）→ `remote: Repository not found`。
3. `Set-Content -Encoding utf8` 在 PS 5.1 会带 BOM；`.gitignore` 首行必须是注释，否则 BOM 会污染第一条规则。
4. `warning: LF will be replaced by CRLF` 无害，Windows 默认行为。
5. 网页建仓库时若勾了 README，首次 push 会 `rejected`，需 `git pull --rebase origin main --allow-unrelated-histories`。
